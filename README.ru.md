# 2izi Screenshot

Скриншот всей страницы или выделенной области — сразу в JPG. Никаких вкладок
с превью, никаких лишних окон — один клик, один файл в папке загрузок.

🇬🇧 [Read in English](README.md)

## Возможности

- **Вся страница** — прокручивает и склеивает страницу целиком в одно
  изображение
- **Выделить область** — выделение в стиле macOS: курсор-перекрестие,
  размер в реальном времени, `Esc` для отмены
- Сохраняет сразу в `.jpg` через API загрузок браузера — ничего не
  открывается в новой вкладке или редакторе
- Вся обработка на 100% локальная — данные никогда не покидают браузер
  (см. [Политику конфиденциальности](docs/PRIVACY.ru.md))
- Интерфейс на русском и английском (определяется по языку браузера)

## Установка

**Из Chrome Web Store:** [ссылка на карточку после публикации]

**Из исходников (режим разработчика):**

1. Скачай или склонируй репозиторий
2. Открой `chrome://extensions`
3. Включи **Режим разработчика** (справа вверху)
4. Нажми **«Загрузить распакованное расширение»** и укажи папку `extension/`

## Как это работает

Клик по иконке в панели инструментов, затем:

- **«Вся страница»** — расширение прокручивает страницу шагами размером с
  вьюпорт, снимает каждый шаг и склеивает их в одно изображение через
  `OffscreenCanvas` в фоновом service worker'е.
- **«Выделить область»** — content-скрипт рисует полноэкранный оверлей для
  выделения мышью; после отпускания кнопки фоновый скрипт снимает видимую
  область вкладки и обрезает её по выделению.

В обоих случаях результат конвертируется в JPEG и передаётся в
`chrome.downloads.download` с `saveAs: false` — файл сразу попадает в папку
загрузок.

## Структура проекта

```
extension/          собственно расширение (грузить как распакованное)
  manifest.json
  background.js      склейка полной страницы, обрезка выделения, сохранение JPG
  content.js          оверлей выделения области
  popup.html/.js       интерфейс попапа
  icons/                иконки 16/32/48/128 px
  _locales/en, /ru       строки интерфейса
docs/                политика конфиденциальности (EN/RU)
store/               тексты карточки Chrome Web Store (EN/RU)
```

## Разрешения

| Разрешение   | Зачем |
|--------------|-------|
| `activeTab`  | Снимок вкладки, которую вы просматриваете, только после клика по иконке |
| `scripting`  | Внедрение оверлея выделения / скролл-хелпера на активной вкладке |
| `downloads`  | Сохранение готового JPEG в папку загрузок |

Нет разрешений на «все сайты», нет фоновой активности без вашего действия.
Подробности — в [docs/PRIVACY.ru.md](docs/PRIVACY.ru.md).

## Известные ограничения

- При съёмке всей страницы `position: sticky` / `fixed` шапки могут
  дублироваться на стыках сегментов — особенность подхода
  «скролл + склейка» (альтернатива — `chrome.debugger`, но он показывает
  заметную плашку «расширение отлаживает эту вкладку»).
- Нельзя снимать страницы `chrome://` и сам Chrome Web Store — это
  ограничение браузера, а не расширения.
