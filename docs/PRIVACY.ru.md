# Политика конфиденциальности — 2izi Screenshot

**Обновлено:** сентябрь 2026
**Издатель:** TWOIZIRU (2izi.ru)
**Контакты / поддержка:** https://2izi.ru/support

## Кратко

2izi Screenshot не собирает, не хранит, не передаёт и не продаёт никакие
пользовательские данные. Вся обработка происходит локально, внутри вашего
браузера, на вашем устройстве.

## Что делает расширение

- Делает снимок видимой области вкладки и/или прокручивает страницу для
  сборки полного скриншота с помощью встроенного API Chrome
  `tabs.captureVisibleTab`.
- Обрезает или склеивает изображение локально, используя canvas в памяти.
- Конвертирует результат в JPEG и сохраняет файл на ваш компьютер через
  API `downloads`.

Ни изображение, ни адрес страницы, ни её содержимое, ни какие-либо другие
данные никогда не отправляются на наши серверы или третьим лицам. У этого
расширения нет бэкенда — ему попросту не с кем "разговаривать".

## Используемые разрешения и зачем они нужны

| Разрешение   | Зачем нужно |
|--------------|-------------|
| `activeTab`  | Позволяет расширению читать и снимать ту вкладку, которую вы просматриваете, и только после клика по иконке расширения. |
| `scripting`  | Внедряет небольшой скрипт, который рисует рамку выделения и прокручивает страницу при съёмке всей страницы. Работает только на активной вкладке и только после вашего действия. |
| `downloads`  | Сохраняет готовый JPEG-файл в папку загрузок. |

Расширение не запрашивает разрешения на "все сайты" и не работает в фоне
без вашего участия — оно активируется только при клике по иконке и выборе
«Вся страница» или «Выделить область».

## Хранение данных

Поскольку никакие данные не покидают ваше устройство, нам нечего хранить и
нечего удалять по запросу — у расширения просто нет хранилища
пользовательских данных.
